🎯 Hero summary roxo

  • Total geral devendo + faltam X parcelas pra zerar — a métrica que importa mental e emocionalmente.
  • 3 stats inline: este mês / próximo mês / data de liberdade. "Liberta em jan/27" é storytelling — mostra que tem fim.
  • Cor roxa diferencia esta seção das outras (coral = pendência, teal = composição, roxo = compromisso de longo prazo).

📊 Progress segmentado vs barra

Ao invés de progress bar contínua, usamos X dots discretos — cada um é uma parcela. Verde = pago, coral pulsante = parcela atual, cinza = pendente. Bate com modelo mental de "quantas faltam".

📦 Densidade & agrupamento

  • Card ~120px de altura vs ~250px do design atual (50% mais denso).
  • 3 grupos contextuais: vencem este mês / vencem mês que vem / recém-quitados.
  • Quitado fica "fantasma" (opacity .7 + line-through no nome) + stamp verde "✓ Quitado".
  • Pills coloridas no footer: vermelho = vence em 4 dias / verde = 80% pago / âmbar = próxima.

🎨 Hierarquia clara

Cada parcela: emoji 22px → nome 15px bold → meta 12px com payer-dot → installment "3 de 12" em coral monospace-feel → progress segmentado → footer com restantes + valor + pill contextual. Sempre na mesma ordem visual.
