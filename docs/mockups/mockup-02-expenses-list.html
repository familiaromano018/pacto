🔍 Estratégia de densidade

  • Agrupamento contextual: "esta semana" / "parcelas em aberto" / "fixos do mês" — usuário escaneia por categoria mental, não por data crua.
  • Cada grupo tem total no header, então a soma é óbvia sem precisar somar mentalmente.
  • Row densa (~62px altura): emoji + desc + pagador-dot + valor + tag tipo + meta extra. Cabem ~10 itens visíveis sem scroll.

🎯 Filtros & busca

  • Chips horizontais scrolláveis: Todos · Ana · Pedro · Casal · Fixos · Parcelados. Ana/Pedro com border colorido = visual identity de cada pessoa.
  • Payer-dot de 14px com inicial — micro avatar inline. Casal = dot split coral/teal.
  • Total bar persistente reflete o filtro atual em tempo real (R$ 5.823 → muda conforme filtra).
  • Sort button à direita do total bar (mais recente / valor / categoria).

🪙 Empty state

Ilustração com emoji grande em círculo gradient (pastel rosa-âmbar). Copy brincalhão mantém tom. CTA primário coral, secundário inline com keyboard shortcut tip — esse detalhe sinaliza app de gente que usa.
